## ⚠️ Gotchas
- **On the host, not the lean-yolo-box** — `git push`/`gh`/rebase all work. But
  `git rebase -i` is unavailable in this harness; squash via `git reset --soft
  <base> && git commit -C <tip>` (used it this session).
- **Repo flow:** feature branch → `gh pr create --base main` → `gh pr merge N
  --merge` → `git checkout main && git pull` → delete branch local+remote. Don't
  chain the delete+push in one Bash call (got permission-denied; run separately).
- **Bare `lake build` skips unimported modules** — build new files explicitly
  (`lake build FiniteSimpleGroups.X`) and wire them into the root `FiniteSimpleGroups.lean`.
- There's a master `HANDOFF.md` + dated `HANDOFF-*.md`. This is a dated session
  doc; **don't overwrite the master.**
