## 1 + 2. The proof, from Kurzweil–Stellmacher §6.5 (verified verbatim)

K-S, *The Theory of Finite Groups: An Introduction* (Springer Universitext, 2004),
**§6.5 "Components and the Generalized Fitting Subgroup", pp. 141–145.** OCR
artifacts corrected by hand and cross-checked against the page scan. This is the
clean writeup the request hoped for; I did **not** need Aschbacher (see §note).

### Definitions (p. 141)

* **quasisimple**: `K ≠ 1` is quasisimple iff `K` is perfect (`K' = K`) and `K/Z(K)`
  is simple. — Key consequence used throughout: for every subnormal `N ⊴⊴ K` of a
  quasisimple `K`, *either* `N ≤ Z(K)` *or* `N = K`; hence **nontrivial homomorphic
  images of quasisimple groups are quasisimple.**
* **component**: a subgroup `K ≤ G` that is quasisimple *and* subnormal in `G`.
  Inheritance (all three are used):
  1. `K ≤ U ≤ G ⟹ K` is a component of `U`;
  2. `K ⋬ N ⊴ G ⟹ KN/N` is a component of `G/N`;
  3. `K` a component of a subnormal subgroup of `G ⟹ K` a component of `G`.
  Minimal subnormal subgroups are simple; the non-abelian ones are exactly the
  components.

### The lemma chain

**6.5.1** *(the central-quotient pullback — THE lemma the repo axiom needs).*
Let `Z, E ≤ G` with `Z ≤ Z(G)` and `EZ/Z` a component of `G/Z`. **Then `E'` is a
component of `G`.** (`E' = [E,E]`, the perfect core.)

> *Proof.* Since `Z ≤ Z(G)`, `E' = (EZ)'`, and since `EZ ⊴⊴ G` also `E' ⊴⊴ G`
> (subnormal). By 1.5.3 (p. 25) `E'` is perfect. Let `N ⊴ E'` and `Ḡ := G/Z`. As
> `Ē = ĒZ/Z = EZ/Z` is quasisimple, either `N̄ = Ē = Ē'` or `N̄ ≤ Z(Ē)`.
> *First case:* `N ≤ E' ≤ NZ`, so `N(Z ∩ E') = E'`, whence `N = E'` since `E'` is
> perfect. *Second case:* `[E', N] ≤ Z`, so `[E',N,E'] = 1 = [N,E',E']`; the
> **Three-Subgroups Lemma** (1.5.6, p. 26) gives `[E',E',N] = 1`, hence `[E',N] = 1`
> (again `E'` perfect), so `N ≤ Z(E')`. Either way `N ≤ Z(E')` or `N = E'`, so `E'`
> is quasisimple. With `E' ⊴⊴ G` perfect quasisimple, `E'` is a component of `G`. ∎

**6.5.2** Let `K` be a component of `G`, `U ⊴⊴ G`. Then `K ≤ U` or `[U,K] = 1`.
(Induction on `|G|` via `N_N(U₁)` where `U₁ = [U,K]`, + Three-Subgroups Lemma.)

**6.5.3** Components `K₁, K₂` of `G`: either `K₁ = K₂` or `[K₁,K₂] = 1`. **Distinct
components commute.** Hence products of components are subgroups. (Immediate from
6.5.2.)

**Definitions (p. 143).** `E(G)` := subgroup generated by the components (**the
layer**); `F*(G) := F(G)·E(G)` (**the generalized Fitting subgroup**). By 6.5.2,
**`[F(G), E(G)] = 1`** (so `F*` is a central product of `F(G)` and `E(G)`).

**6.5.4** `F*(G)` contains every minimal normal subgroup of `G`; in particular
`F*(G) ≠ 1` if `G ≠ 1`. (From 1.7.3: a minimal normal is abelian-and-`≤F(G)`, or a
product-of-components-and-`≤E(G)`.)

**6.5.5** (a) component `K` with `Z(K)=1` ⟹ `⟨K^G⟩` is a minimal normal subgroup =
direct product of the `G`-conjugates of `K`. (b) `F(G)=1 ⟹ E(G)` is the product of
the minimal normal subgroups of `G`. (Uses 6.3.1: `Z(K) ≤ F(G)` for every
component.)

**6.5.6** `E(G) ≠ 1`, components `K₁,…,Kₙ`; `Z := Z(E(G))`, `Zᵢ := Z(Kᵢ)`,
`Eᵢ := KᵢZ/Z`. Then (a) `E(G)` is the central product of `K₁…Kₙ`, `Z = Z₁…Zₙ`;
(b) `Zᵢ = Z ∩ Kᵢ`, `Eᵢ ≅ Kᵢ/Zᵢ`; (c) **`E(G)/Z = E₁ × … × Eₙ`** — i.e.
`E(G)/Z(E(G))` is a direct product of non-abelian simple groups.

**6.5.7** `L ⊴⊴ G`. (a) `L ≤ F*(G) ⟹ L = (L∩F(G))(L∩E(G))`. **(b) `F*(L) = F*(G) ∩ L`.**
(c) `E(L) ⊴ E(G)`. [(c)'s exact equation is OCR-garbled in the digitized copy; the
load-bearing part is **(b)**, and `E(L) ≤ E(G)`, `E(L) ⊴ E(G)`.] — **(b) is the
monotonicity the repo already has as `genFittingSubgroup_map_subtype_le`** (the `≤`
half: `F*(N).map ≤ F*(G)` for `N ⊴ G`).

**6.5.8 Theorem** *(Bender's cornerstone; "generalizes 6.1.4", the solvable case).*
`C_G(F*(G)) ≤ F*(G)`.

> *Proof.* Let `L := C_G(F*(G))` (normal in `G`), `Z := Z(L)`, `L̄ := L/Z`. It
> **suffices to show `F*(L̄) = 1`**: then `L̄ = 1` (6.5.4), so `L = Z = Z(L)` is
> abelian; an abelian normal subgroup is nilpotent normal, so `L ≤ F(G) ≤ F*(G)`.
> By 6.5.7(b), `F*(L) ≤ F*(G)`; but `L` centralizes `F*(G)`, so
> `F*(L) ≤ F*(G) ∩ C_G(F*(G)) ≤ Z(L) = Z`, and `Z = Z(L) ≤ F*(L)` always, hence
> **`F*(L) = Z`**.
> *`F(L̄) = 1`:* the preimage in `L` of the nilpotent normal `F(L̄) ⊴ L̄ = L/Z` is
> nilpotent (central-by-nilpotent, 5.1.2, p. 100) and normal in `L`, so it lies in
> `F(L) ≤ F*(L) = Z`; thus `F(L̄) = Z/Z = 1`.
> *`E(L̄) = 1`:* if `F*(L̄) ≠ 1` then (as `F(L̄)=1`) `L̄` has a component `Ē = EZ/Z`,
> `Z < E ≤ L`. By **6.5.1**, `E'` is a component of `L`, so `E' ≤ E(L) ≤ F*(L) = Z`;
> but `Z = Z(L)` is abelian and `E'` is quasisimple (non-abelian) — contradiction.
> Hence `F*(L̄) = 1`. ∎

**Read this:** K-S's 6.5.8 proof reduces the whole cornerstone to **6.5.1** (for the
layer part) + 5.1.2 (central-by-nilpotent, for the Fitting part). It does **not**
detour through a separate "`G` is solvable" induction. The repo's `bender_aux` is
the same `C_G(F*)`-induction skeleton; the repo's residual axiom
`layer_quotient_center_eq_bot` is exactly the 6.5.1 step. **6.5.1 is the unblock.**

## Discharging `layer_quotient_center_eq_bot` — the portable lemma list

Target: `layer G = ⊥ → layer (G ⧸ center G) = ⊥`. This is the **contrapositive of
K-S 6.5.1 specialized to `Z = Z(G)`**: a component of `G/Z(G)` produces a component
of `G`, so no components in `G` ⟹ no components in `G/Z(G)`.

The repo docstring already lists most bricks as proved. Formalize 6.5.1 as:

1. **Pick a component `L̄` of `Ḡ := G/Z(G)`.** Set `E := comap π L̄` (so
   `EZ/Z = L̄`, `E ⊇ Z(G)`). `E ⊴⊴ G` — repo `IsSubnormal.comap_top` ✅ proved.
2. **`E' := ⁅E,E⁆` is subnormal in `G`** — characteristic in the subnormal `E`;
   repo `IsSubnormal.of_characteristic_subgroupOf` ✅ proved.
3. **`E'` is perfect** (`⁅E',E'⁆ = E'`). K-S cites its 1.5.3; in the central-
   quotient setting `Ē = L̄` is perfect (quasisimple), and `E' = (EZ)' = (E)'` maps
   *onto* `L̄' = L̄`; the perfect-core idempotence `⁅E',E'⁆ = E'` is the bridge noted
   in `lean-v428-v429-port-gotchas`. ⬅️ this is the "final assembly" TODO.
4. **`E'` is quasisimple.** This is the heart, = "a perfect central extension of a
   quasisimple group is quasisimple." Decompose exactly as K-S's 6.5.1 proof:
   for `N ⊴ E'`, the image `N̄ ⊴ Ē` (quasisimple) gives `N̄ = Ē` or `N̄ ≤ Z(Ē)`;
   * `N̄ = Ē` ⟹ `N = E'` (perfect, via `N(Z∩E') = E'`);
   * `N̄ ≤ Z(Ē)` ⟹ `[E',N] ≤ Z(G)` ⟹ (Three-Subgroups Lemma, `[E',N,E']=1=[N,E',E']`
     ⟹ `[E',E',N]=1` ⟹ `[E',N]=1` since `E'` perfect) ⟹ `N ≤ Z(E')`.
   So every `N ⊴ E'` is `≤ Z(E')` or `= E'`, i.e. `E'/Z(E')` is simple and `E'` is
   perfect ⟹ `E'` quasisimple. **Grün's lemma** `center_quotient_center_eq_bot_of_perfect`
   ✅ (PerfectCentralExtension.lean) is the `Z(E'/Z(E'))=1` fact that closes it;
   you also need mathlib's **Three-Subgroups Lemma** (`Subgroup.commutator_commutator_*`
   / `three_subgroups_lemma` — present in mathlib's commutator file) and the
   central-commutator step you already have as `commutator_sup_central_eq` /
   `commutatorElement_mul_central`.
5. **`E'` is a component of `G`** (`IsComponent E' = IsSubnormal E' ⊤ ∧ IsQuasisimple E'`)
   ⟹ `E' ≤ layer G`, contradicting `layer G = ⊥` (since `E'` quasisimple ⟹ `E' ≠ ⊥`).

Net: steps 1, 2 are done; Grün (step 4's closer) is done; the open work is the
**perfect-core idempotence (3)** and the **`N̄ = Ē`/`N̄ ≤ Z(Ē)` case split (4)** —
i.e. literally formalize the four-line K-S 6.5.1 proof above. (Aristotle job
`9f7b6b74` was already aimed at "perfect central extension of quasisimple is
quasisimple" = step 4; this gives it the exact K-S proof to follow.)
