## 🧠 The arc (mental model)

The Bender cornerstone `genFittingSubgroup_self_centralizing` (`C_G(F*(G)) ≤ F*(G)`) was a
theorem-by-induction resting on a soluble base-case axiom. The base case is: `layer G = ⊥` (no
components) + `F(G) ≤ Z(G)` ⟹ `F(G) = ⊤`. This lap marched that axiom down to almost nothing:

1. **Ported Aristotle's solvable kernel** (`fittingSubgroup_eq_top_of_isSolvable_of_le_center`,
   `SolubleFittingKernel.lean`): `[IsSolvable G] → F(G)≤Z(G) → F(G)=⊤`. A real theorem, axiom-free.
   So the base case reduces to proving **solvability**.

2. **The key realization that unlocks the induction.** I'd feared the solvability induction was
   circular (the naive "quotient by `Z(G)`" induction seems to need `F(G/Z) ≤ Z(G/Z)`, which
   isn't inherited). It is NOT circular: under `F(G) ≤ Z(G)` (so `F(G) = Z(G)`), the quotient has
   **`F(G/Z(G)) = ⊥`** — any nilpotent normal subgroup of `G/Z(G)` pulls back to a central
   extension of a nilpotent group, hence nilpotent, hence `≤ F(G) = Z(G)`, hence trivial downstairs.
   This is `fittingSubgroup_quotient_center_eq_bot` (`SolubleFittingKernel.lean`), proved.

3. **The solvability induction** `isSolvable_aux` (`GeneralizedFitting.lean`), strong induction on
   `|G|`: `Z=⊤` → abelian; `Z=⊥` → a minimal normal (abelian since `layer=⊥`) would sit in
   `F(G)=⊥`, impossible, so `G` trivial; `⊥<Z<⊤` → `Ḡ=G/Z` is smaller with `F(Ḡ)=⊥` and (by the
   residual axiom) `layer Ḡ=⊥`, so `Ḡ` solvable by IH and `G` is the extension of abelian `Z` by
   solvable `Ḡ` (`solvable_of_ker_le_range`). **The ONLY axiom this uses is
   `layer_quotient_center_eq_bot`.**

4. **Discharging the residual axiom (in progress).** `layer_quotient_center_eq_bot` says: a
   component `L̄` of `G/Z(G)` pulls back to a component of `G`. Proof plan, with bricks built:
   - `IsSubnormal.comap_top` (`Subnormal.lean`, **proved**): `comap π L̄` is subnormal in `G`.
   - `IsSubnormal.of_characteristic_subgroupOf` (`Subnormal.lean`, **proved**): the perfect core
     `⁅comap π L̄, ·⁆` (characteristic) is subnormal in `G`.
   - `center_quotient_center_eq_bot_of_perfect` (**Grün's lemma**, `PerfectCentralExtension.lean`,
     **proved**, axiom-free, via the three subgroups lemma): `Z(K/Z(K)) = ⊥` for perfect `K`.
   - **TODO (the only remaining piece):** "a perfect central extension of a quasisimple group is
     quasisimple" — i.e. for `H` finite, `C ≤ Z(H)`, `IsQuasisimple (H/C)`, conclude
     `IsQuasisimple ↥(commutator H)`. Then assemble: the perfect core of `comap π L̄` is a
     quasisimple subnormal subgroup of `G` = a component, contradicting `layer G = ⊥`.
