## 🧠 Context to carry forward

- **`burnside_simple` is now proved** (`FiniteSimpleGroups/Burnside.lean`) by the classical
  Sylow/centre reduction — machine-checked — to one sharp axiom
  `isSimpleGroup_centralizer_index_not_primePow`: *a finite simple group has no conjugacy class of
  prime-power size > 1* (i.e. `(centralizer {g}).index ≠ p^k` for `g≠1`, `k≥1`). This IS Burnside's
  prime-power class-size lemma (Isaacs *Character Theory* 3.8). Audited true this lap (abelian-simple
  = prime-cyclic gives index 1 = p^0, excluded by `k≥1`).
- **Key reduction insight**: you do NOT need two distinct primes. Pick ONE prime `s | |G|`, a Sylow
  `s`-subgroup `P`, a nontrivial `z ∈ Z(P)`. Since `Z(G)=⊥` (noncomm simple), `z` is non-central, so
  `N=[G:C_G(z)] > 1`; `N | [G:P]` so `s ∤ N`; every prime of `N` divides `|G|` (∈{p,q}) and ≠ s ⇒ all
  equal ⇒ `N = t^k` prime power ⇒ contradiction. (The "all primes of N equal" step is `key`, an
  8-way `simp_all` case bash.)
- **The sharp axiom decomposes into 6 ingredients** (full map in `CharacterTheory.lean` top docstring).
  Status after this lap: **1,4,5,6 DONE; only 2,3 missing.**
  - (1) `χ(g)` algebraic integer — ✅ `Representation.character_isIntegral`.
  - (4) Kronecker — ✅ ALREADY in mathlib: `NumberField.Embeddings.pow_eq_one_of_norm_le_one`.
    (Handoff before this lap wrongly implied it was absent. It's there.)
  - (5) `-1/p ∉ ℤ̄` — ✅ `not_isIntegral_neg_inv_prime`.
  - (6) scalar ⟹ proper normal subgroup — ✅ `scalarSubgroup`, `scalarSubgroup_normal`,
    `comm_of_scalarSubgroup_eq_top`.
  - (2) **central-character integrality** `[G:C_G(g)]·χ(g)/χ(1) ∈ ℤ̄` — ⛔ needs class sums /
    `Z(ℂ[G])`, NOT in mathlib v4.29.1.
  - (3) **column orthogonality** `∑_χ χ(1)χ(g)=0` (g≠1) — ⛔ mathlib has only row orthonormality.

## ⚠️ Gotchas

- **`rw`/`▸` "motive is not type correct"** when the rewritten value hides in a dependent type
  (`s` inside `P : Sylow s G` inside `z`'s type). Fix: rewrite the equation inside a *plain-typed*
  hypothesis (`rw [h] at (Nat.minFac_dvd N : … ∣ …)`), never the goal. (Flushed to KB staging.)
- **`set` breaks `▸`**: using `set t := …` then `h ▸ …` triggers the binder-revert failure. Keep the
  expression inline, or rewrite inside a hyp.
- **OOM-thrash**: full `lake build` intermittently "Cannot allocate memory" on an unrelated mathlib
  module — just retry (didn't hit it this lap, but prior laps did).
- Aristotle prefers toolchain v4.28.0; our pin is v4.29.1 — always re-verify returned proofs in our
  kernel before trusting. Copy `lean-toolchain` into the `--project-dir`.
