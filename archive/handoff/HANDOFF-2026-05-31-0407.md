## 🧠 Context to carry forward
- This repo defines its **own** `IsSubnormal H K := Relation.ReflTransGen IsNormalStep H K`
  in `FiniteSimpleGroups/Subnormal.lean`, where `IsNormalStep A B := A ≤ B ∧ (A.subgroupOf B).Normal`.
  The warm-up proof = prove the single step `isNormalStep_sup_right` (A◁B ⟹ A⊔N◁B⊔N)
  then `Relation.ReflTransGen.lift (·⊔N)` up the chain, with `top_sup_eq` to close `⊤⊔N=⊤`.
- The single step: `normal_subgroupOf_iff_le_normalizer` reduces normality to
  `B⊔N ≤ normalizer ↑(A⊔N)`. `sup_le` splits it: **N-part** is trivial
  (`N ≤ A⊔N ≤ normalizer` via `Subgroup.le_normalizer`); **B-part** is the content —
  `b∈B` fixes `A⊔N` by conjugation. Key kit (all confirmed in mathlib v4.29.1):
  `conjAct_pointwise_smul_iff : ConjAct.toConjAct g • H = H ↔ g ∈ normalizer H`,
  then `smul_sup` splits the conj of the join, `conjAct_pointwise_smul_eq_self` fixes A,
  `Normal.conjAct` fixes N.
- **Dead end avoided** (cost me two false starts): the pointwise conjugation action on
  `Subgroup G` is by `ConjAct G` / `MulAut.conj g`, **not** `g` directly — `g • H` fails
  HSMul synthesis. And `Subgroup.normalizer` takes a **`Set G`**, so `H.normalizer`
  dot-notation fails; write `Subgroup.normalizer (H : Set G)` / rely on the coercion in
  `normalizer ↑H`. (Existing memory [[mathlib-normalizer-centralizer-take-set]].) I first
  tried hand-rolling normalizer↔smul bridges with `mem_normalizer_iff_smul` (that's the
  Set-translation smul, wrong) and `MulAut.conj` + simp — both fragile. The clean answer
  is mathlib's ready-made `conjAct_pointwise_smul_iff`. Use it; don't re-derive.
- **For the full join `IsSubnormal.sup`**: standard route is `[A,B]`-three-subgroups
  argument, harder. Worth first checking whether **mathlib's own** `Subgroup.IsSubnormal`
  (see Gotchas) already has a join lemma you can port/wrap, rather than building on the
  repo's `ReflTransGen` encoding from scratch.
